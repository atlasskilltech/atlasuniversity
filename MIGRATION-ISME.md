## How the count was made

Every `.php` file under `reference/schools/isme/` outside `assets/` — **178**. The seven files
under `assets/include/` (`header.php`, `footer.php`, `dynamic.php`, `explore-by-experience.php`,
`bba-major-minor-common-section.php` and the two dated variants `header-isme-27-feb.php` /
`footer_new.php`, which no page includes) are shared includes, not pages. Three more includes
the pages use live in the ATLAS root reference: `reference/assets/include/more-questions.php`,
`faq.php` (database-driven) and `faq/isme/**`.

Each URL was checked against production with the map audit, one request at a time
(`data/map/isme-production-check.json`): **178/178 exist** — 177 answered 200 and one answered
429 (rate-limited, not missing). 17 folder pages 301 to their trailing slash. No soft-404s.

Upstream `<title>`s are often copy-pasted — 52 pages carry the generic “ATLAS SkillTech
University”, seven Marketing-major pages all say “with Finance” — but every URL serves distinct
content, so every file is its own page.

`blog/index.php` is the **blog detail template** (reads a slug and calls the blogs API), so its
route is dynamic — the same treatment `/schools/isdi/blog/[slug]` and `/atlas-blog/[slug]` got.
`life@atlas-isme/test.php` is a 1908-line test file that production nevertheless serves; it is
tracked like every other page. (Built 2026-11-02: its body is the Life hero, the anchor menu and a
300vh red-bordered scroll-test `<p>`; it inlines ISME's header and has no footer — see its row.)

## Reuse plan (verified against the code before writing anything)

- **Header** — the ISME `header.php` is the same Webflow chassis as ISDI's (45 of 56 classes
  shared). `components/Schools/ISDI/Header` is generalised to take a `site` (menu model, CTAs,
  logo, accent) with ISDI's values as the defaults, so ISDI renders exactly as before. ISME
  differences, measured on production: Manrope (not Poppins), #009FE0 utility bar, mint #07F6A0
  CTAs / nav underline / row highlight (weight 600, dark text), 232×52.7 logo (150×34.1 ≤991),
  a 600px BBA third level.
- **Footer** — different content shape (contact list with three phone lines, “Meet us”, navy
  #072058 columns over its own vector), so `components/Schools/ISME/Footer`; it mounts the
  existing `components/Footer/VideoModal` like the ISDI footer does.
- **Instagram** — `components/Home/InstagramFeed` + `lib/instagram/posts#getInstagramFeed`,
  exactly as `components/Schools/ISDI/Home/ActionNeverStops` uses them. No new Instagram code.
- **Chrome exclusion** — `components/Schools/MainSiteOnly` already hides the ATLAS header and
  footer on `/schools/*`; `app/schools/isme/layout.js` mounts the ISME chrome.
- Section components from the ISDI port (`components/Schools/ISDI/**`, `components/ui/**`) are
  reused as data-driven components wherever the ISME markup is the same shape.
